# 面试八股高频问答

## 1. Vue / 前端

### 问：Vue2 和 Vue3 的区别是什么？

答：

> Vue2 主要用 Options API，Vue3 更强调 Composition API。Vue3 在逻辑复用、类型支持、复杂页面组织上更强，响应式实现也更现代。

### 问：`ref` 和 `reactive` 有什么区别？

答：

> `ref` 更适合单值，访问时需要 `.value`；`reactive` 更适合对象，直接改属性即可。它们本质上都是让数据具备响应式能力。

### 问：`computed` 和 `watch` 的区别？

答：

> `computed` 用来派生一个值，有缓存；`watch` 用来监听变化并执行副作用，比如调接口、同步缓存、埋点。

### 问：Vue 生命周期怎么理解？

答：

> 生命周期就是组件从创建、挂载、更新到销毁的过程。开发里常在 `mounted/onMounted` 拉数据，在 `unmounted/onUnmounted` 清理事件和定时器。

### 问：uni-app 的 `onLoad` 和 `onShow` 区别？

答：

> `onLoad` 更像首次进入页面时触发，常用来拿参数；`onShow` 是页面每次显示都会触发，适合做回显和刷新。

### 问：为什么表单初始化时先用 `entity` 接数据，再回填表单？

答：

> 因为这样可以把接口返回值固定成一份稳定快照，避免把 `formData.value` 同时当接口数据、页面状态和表单值来源，数据流更清晰。

### 问：什么是前端路由？

答：

> 路由就是 URL 和页面组件之间的映射关系。前端路由可以在不刷新整个页面的情况下切换组件视图。

### 问：`v-if` 和 `v-show` 区别？

答：

> `v-if` 是真正创建和销毁节点，适合不频繁切换；`v-show` 是改 `display`，适合频繁切换。

### 问：为什么列表渲染要加 `key`？

答：

> `key` 用来帮助 Vue 正确识别节点身份，提升 diff 准确性，避免错误复用 DOM。

## 2. Java 基础

### 问：JDK、JRE、JVM 的区别？

答：

> JDK 是开发工具包，JRE 是运行环境，JVM 是真正执行字节码的虚拟机。

### 问：`==` 和 `equals` 区别？

答：

> `==` 比较地址，基本类型比较值；`equals` 一般比较内容，具体取决于类是否重写。

### 问：`String` 为什么不可变？

答：

> 因为它内部值不能被修改，这样便于缓存、线程安全和字符串常量池复用。

### 问：`ArrayList` 和 `LinkedList` 区别？

答：

> `ArrayList` 底层是数组，查找快；`LinkedList` 底层是链表，插删中间节点更方便，但随机访问慢。

### 问：`HashMap` 为什么快？

答：

> 因为它通过 key 的 hash 快速定位桶，再结合链表或红黑树查找，平均时间复杂度接近 O(1)。

## 3. 并发

### 问：线程和进程的区别？

答：

> 进程是资源分配单位，线程是 CPU 调度单位。一个进程可以包含多个线程。

### 问：为什么要用线程池？

答：

> 线程池可以复用线程，减少频繁创建销毁开销，并且能控制并发数量，防止系统资源被打满。

### 问：`synchronized` 和 `volatile` 区别？

答：

> `synchronized` 能保证原子性、可见性和有序性；`volatile` 主要保证可见性和一定程度有序性，但不保证复合操作原子性。

### 问：什么是 CAS？

答：

> CAS 是 Compare And Swap，先比较内存中的值是否还是预期值，如果是就更新，否则重试，常用于无锁并发。

### 问：什么是死锁？

答：

> 多个线程互相等待对方释放资源，导致谁都执行不下去，就是死锁。

## 4. JVM

### 问：JVM 内存结构有哪些？

答：

> 常见理解是堆、栈、方法区。堆放对象实例，栈放方法调用和局部变量，方法区放类信息和常量。

### 问：Java 判断对象是否可回收主要靠什么？

答：

> 主要靠可达性分析，不是单纯引用计数。

### 问：什么是 GC？

答：

> GC 就是垃圾回收，负责清理堆中不再使用的对象，释放内存。

## 5. Spring / Spring Boot

### 问：什么是 IOC？

答：

> IOC 是控制反转，本来对象由代码自己 `new`，现在交给 Spring 容器管理。

### 问：什么是 AOP？

答：

> AOP 是面向切面编程，用来抽离日志、事务、权限、监控这类横切逻辑。

### 问：Spring Boot 为什么好用？

答：

> 因为它提供自动装配、内嵌容器和约定优于配置，能快速启动项目，减少大量样板代码。

### 问：`@Transactional` 为什么会失效？

答：

> 常见原因是同类内部自调用、方法没有经过 Spring 代理，或者抛出的异常类型没有触发默认回滚。

### 问：Bean 生命周期大概是什么？

答：

> 实例化、依赖注入、初始化、使用、销毁。常见扩展点有 `@PostConstruct` 和 `@PreDestroy`。

## 6. MySQL

### 问：索引是什么？

答：

> 索引是帮助数据库快速定位数据的数据结构，本质是用空间换时间。

### 问：为什么 InnoDB 常用 B+ 树做索引？

答：

> 因为 B+ 树高度低、磁盘 IO 少，并且天然适合范围查询。

### 问：聚簇索引和二级索引区别？

答：

> 聚簇索引的数据和索引放在一起，二级索引先查索引再回表找数据。

### 问：事务的 ACID 是什么？

答：

> 原子性、一致性、隔离性、持久性。

### 问：MySQL 隔离级别有哪些？

答：

> 读未提交、读已提交、可重复读、串行化。InnoDB 默认是可重复读。

### 问：什么是 MVCC？

答：

> MVCC 是多版本并发控制，通过多版本数据让读写尽量不互相阻塞，提高并发能力。

### 问：索引什么时候会失效？

答：

> 常见情况有对索引列做函数、like 以 `%` 开头、隐式类型转换、违反最左前缀原则。

## 7. Redis

### 问：Redis 为什么快？

答：

> 因为它基于内存、数据结构简单、单线程避免锁竞争、网络模型高效。

### 问：Redis 常见数据结构有哪些？

答：

> `String`、`Hash`、`List`、`Set`、`ZSet`。

### 问：缓存穿透、击穿、雪崩区别？

答：

> 穿透是查不存在的数据；击穿是热点 key 过期瞬间并发打库；雪崩是大量 key 同时过期把数据库打垮。

### 问：Redis 分布式锁怎么做？

答：

> 常见方式是 `SET key value NX EX`，核心是原子加锁、设置过期时间、解锁时避免误删别人的锁。

## 8. MQ

### 问：为什么要用消息队列？

答：

> 为了解耦、削峰和异步化。比如下单后发券、发通知、积分处理不一定要同步完成。

### 问：什么是幂等？

答：

> 同一个操作执行一次和执行多次，结果保持一致。常用于支付回调、下单重试、MQ 重复消费。

### 问：MQ 为什么会重复消费？

答：

> 因为网络抖动、消费重试、确认机制等都可能导致同一消息被再次投递，所以消费端必须做幂等。

### 问：消息丢失怎么处理？

答：

> 生产端确认、Broker 持久化、消费端确认，这三层都要考虑。

## 9. 接口 / 架构

### 问：什么是 RESTful？

答：

> RESTful 是一种接口设计风格，用 URL 表示资源，用 HTTP 方法表示操作。

### 问：什么是前后端分离？

答：

> 前端负责页面和交互，后端负责接口和业务，双方通过 HTTP/JSON 通信。

### 问：什么是鉴权？

答：

> 鉴权就是确认当前请求是否有访问权限，常见方式是 token、session、JWT。

### 问：什么是限流？

答：

> 限流就是控制单位时间内的请求量，避免服务被突发流量打垮。

答法模板：

## 11. 全栈链路题

### 问：一次请求从前端到后端怎么走？

答：

> 前端发起请求，请求进入网关或服务端 Controller，做参数校验后进入 Service，必要时访问 Redis 和 MySQL，涉及异步链路时发 MQ，最后封装响应返回前端。

### 问：你怎么理解全栈工程师？

答：

> 全栈不一定要求每一层都极深，但至少要能把前端、后端、数据库、缓存、消息队列这条链路打通，并能独立定位常见问题。

## 12. 你现在可以直接背的超短版

### Vue

> Vue 的核心是响应式和组件化。Vue2 偏 Options API，Vue3 偏 Composition API。`ref` 适合单值，`reactive` 适合对象，`computed` 用于派生状态，`watch` 用于副作用。组件生命周期常在 mounted 拉数据，在 unmounted 清理资源。uni-app 还要区分 `onLoad` 和 `onShow`。

### Java

> Java 是面向对象语言，常见重点是集合、异常、并发和 JVM。并发里线程池、锁、CAS、可见性和原子性是高频考点。

### Spring

> Spring 核心是 IOC 和 AOP，Spring Boot 通过自动装配提高开发效率。事务依赖代理，所以自调用和异常类型都可能影响事务生效。

### MySQL

> MySQL 重点是索引、事务、MVCC 和锁。索引底层常用 B+ 树，事务关注 ACID 和隔离级别，可重复读是 InnoDB 默认隔离级别。

### Redis

> Redis 重点是缓存和高并发场景。要掌握穿透、击穿、雪崩，以及分布式锁的基本实现思路。

### MQ

> MQ 主要用于解耦、削峰和异步。面试时要重点说幂等、重复消费、消息丢失和顺序消费。
